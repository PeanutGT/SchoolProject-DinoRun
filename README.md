# Dino Run (魔改版小恐龍) 🦖🦖🦖🦖🦖🦖🦖🦖🦖🦖

這是一款基於 JavaFX 開發的 2D 橫向捲軸動作遊戲。本作以經典的 Chrome 網頁小恐龍為靈感，大幅擴充了遊戲的深度與可玩性，加入了雙人合作救援、Boss 彈幕戰鬥、角色扭蛋解鎖以及局外經濟系統，將原本單一的休閒跑酷轉變為具備豐富挑戰性的動作遊戲。

##  核心特色 (Features)

* **多樣化遊戲模式**：支援傳統「單人無盡跑酷」與「雙人合作模式」。雙人模式中加入了獨特的「生命共同體」與「幽靈救援」機制。
* **Boss 戰鬥系統**：突破無盡跑酷的框架，達到指定分數後將觸發 Boss 戰（包含多階段彈幕攻擊與「空洞騎士」Boss）。
* **商店與扭蛋經濟**：在遊戲中收集金幣，並於主選單商店抽取全新外觀角色或解鎖進階能力（如二段跳翅膀特效）。
* **本地排行榜**：內建自定義像素風格的 Top 50 排行榜頒獎台，完整記錄玩家分數與通關角色。
* **豐富道具與技能**：支援多種主動技能（金蘋果救援、無敵護盾、全螢幕清障礙木劍等）。

##  環境需求 (Requirements)

* **Java**: JDK 11 或以上版本。
* **JavaFX**: 需配置對應版本的 JavaFX SDK（若使用 Maven/Gradle 則自動管理）。

##  執行與編譯 (How to Run)

**從 IDE 執行**：
1. 將專案 Clone 至本地端。
2. 確認 IDE (如 IntelliJ IDEA 或 Eclipse) 已正確載入 JavaFX 模組。
3. 將 `com.dino.DinoMain` 設為 Main Class 並執行。

**執行打包檔 (Release)**：
* 直接下載 Release 頁面提供的 `DinoRun.exe`（綠色攜帶版）並點擊執行，存檔與排行榜資料會自動生成於執行檔同層目錄。

##  操作說明 (Controls)

### 單人模式 (Single Player)
* **跳躍**：`W`
* **下蹲**：`S`
* **施放道具技能**：
    * `Q`：金蘋果 (補滿血量)
    * `W`：牛奶 (獲得額外分數與特效)
    * `E`：附魔書 (獲得額外跳躍次數)
    * `R`：護盾 (限時無敵)
    * `F`：木劍 (清除畫面所有障礙物)

### 雙人合作模式 (Co-op Mode)
* **P1 (玩家一)**：`W` (跳躍) / `S` (下蹲) / `Left Shift` (消耗金蘋果復活 P2 並自補)
* **P2 (玩家二)**：`UP` (上鍵跳躍) / `DOWN` (下鍵下蹲) / `Right Shift` (消耗金蘋果復活 P1 並自補)
* *救援機制*：當一方死亡化為幽靈時，存活方跳躍觸碰幽靈即可將其復活。金蘋果技能需擊敗 Boss 後獲得。

### 開發者測試鍵 (Dev Mode)
* `F1`：切換無敵狀態
* `F2` / `F3`：快速增加分數 (用於測試 Boss 觸發)
* `F4`：強制生成道具方塊
* `F5`：強制召喚 Boss

##  系統架構 (Architecture)

本專案採用模組化設計，將邏輯與資源分離：
* **Core (`DinoMain`, `GameConfig`)**：掌控視窗生命週期與全域物理/遊戲數值。
* **Scenes (`GameScene`, `CoopGameScene`, `ShopPanel`)**：封裝各個模式的主迴圈 (`AnimationTimer`) 與介面邏輯。
* **Entities (`Dino`, `Boss`, `Obstacle`)**：處理實體物件的碰撞、狀態機（如幽靈狀態）與物理更新。
* **Managers (`SaveManager`, `LeaderboardManager`, `SoundManager`)**：統一處理檔案 I/O、進度持久化以及音效/資源快取。
