# Chrome 小恐龍遊戲魔改版 (Dino Run Mod)

這是一個以 JavaFX 打造的進階版跑酷遊戲，同時也是中央大學資工系 (NCU CSIE) 的專案作品。在經典的小恐龍玩法上，擴充了 Boss 戰、Minecraft 風格的技能道具系統，以及雙人對戰模式。

## 核心技術與架構亮點 (Features)

* **Delta Time 物理引擎**：遊戲物理與螢幕刷新率 (FPS) 徹底脫鉤，無論在 60Hz 或 144Hz 螢幕上皆有完美一致的遊戲速度。
* **邏輯與渲染分離 (動態縮放)**：內部維持 800x400 虛擬解析度，支援全螢幕無損等比例放大與 UI 完美置中。
* **MVC 架構設計**：主選單與選角畫面採用 FXML 與 Controller 徹底分離，確保 UI 開發與遊戲主迴圈互不干擾。
* **獨立遊戲時鐘 (Game Clock)**：徹底防堵「暫停漏洞」，確保無敵時間與 Boss 戰存活計時與現實時間脫鉤。

## 遊戲特色玩法

* **Boss 生存戰**：具備獨立狀態機，達到特定分數後觸發，需在彈幕與震波中生存 30 秒。
* **技能道具系統**：包含金蘋果 (回血)、牛奶桶 (加分與白霧干擾)、附魔書 (二段跳)、屏障 (清場無敵) 與木劍 (前方掃蕩)。
* **多人對戰與角色選擇**：內建多種角色切換，支援分割畫面的雙人同機遊玩。

## 如何啟動 (How to Run)

本專案開發環境需求為 **JDK 21** 與 **Maven**。
請確保環境安裝完畢後，在專案根目錄下的終端機執行以下指令：

```bash
mvn clean compile javafx:run
```
